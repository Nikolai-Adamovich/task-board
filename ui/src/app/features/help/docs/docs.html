Documentation

Task Board is a modern, collaborative project management application designed to help teams organize, track, and deliver work efficiently. It brings together boards, columns, tasks, and sprints into a unified workspace that adapts to your team's workflow.

Key Features

  • Workspaces & Projects — Create isolated workspaces for different teams or clients, each containing multiple projects with their own boards and settings.
  • Board & Column Management — Organize tasks into customizable columns (e.g., To Do, In Progress, Done) with drag-and-drop support for easy prioritization.
  • Task Tracking — Create, assign, and track tasks with rich details including descriptions, labels, priorities, and due dates.
  • Sprint Planning — Plan iterations using sprints, assign tasks to specific sprints, and monitor progress with burndown-style views.
  • Team Collaboration — Invite team members via email, assign roles (Owner, Admin, Member), and collaborate in real time across shared workspaces.
  • Role-Based Access Control — Fine-grained permissions ensure that team members only access the resources appropriate for their role.

Tech Stack

Task Board is built with a modern TypeScript-first stack. The frontend is powered by Angular with Spartan UI components and Tailwind CSS for styling. The backend runs on Cloudflare Workers with a MongoDB data layer. Shared type definitions and validation schemas ensure end-to-end type safety between client and server.
